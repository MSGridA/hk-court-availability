# HK Tennis Finder

A React + Vite prototype for checking HK LCSD sports court availability.

Current modules:
- Tennis Courts: live availability grid
- Badminton Courts: live availability grid
- Squash Courts: test connection mode

Current features:
- Sport shortcut cards
- 7-day booking date ribbon
- District multi-select chips
- Before / after 2pm switch
- Available-only filter
- Mobile-friendly sports/date ribbons
- Sticky venue column
- SmartPLAY booking link
